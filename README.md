# Практика № 3 · Вариант 19

Конфигурационное управление, ИКБО-42-25. Ассемблер и стековая УВМ.
Python 3.10+; только стандартная библиотека. Сборка и установка не нужны.

## Язык

Исходник — JSON-массив команд в порядке выполнения. Каждая команда —
объект со строкой `op` и ровно одним целым беззнаковым операндом, кроме `shl`.

| Команда | A | B | Действие |
|---|---:|---|---|
| `const` | 1 | `value`: 0…1048575 | Положить константу на стек |
| `read` | 0 | `address`: 0…1023 | Положить на стек значение по адресу |
| `store` | 6 | `offset`: 0…63 | Снять значение, затем адрес; записать значение по адресу + смещение |
| `shl` | 4 | отсутствует | Снять x, затем адрес a; положить x << память[a] |

## Запуск и тесты

```sh
mkdir -p build
sh run.sh asm examples/spec.json build/spec.bin --test
make test
```

Внутренние поля теста: `A=1, B=386`; `A=0, B=526`; `A=6, B=8`; `A=4`.
Каждая инструкция занимает 3 байта (little-endian), A в младших трёх битах,
B начинается с бита 3; свободные старшие биты равны нулю. Размер выводится в байтах.
`encode` упаковывает слово, `byte_listing` форматирует его для `--test`.
Ожидаемый двоичный файл (12 байт): `11 0C 00 70 10 00 46 00 00 04 00 00`.
Это тест кодирования, а не самостоятельная вычислительная программа.
`parse` читает JSON, `parse_row` проверяет поля, `Instruction.fields` выводит A и B.
`parser` описывает CLI, `main` обрабатывает ошибки, `assemble` запускает трансляцию.
